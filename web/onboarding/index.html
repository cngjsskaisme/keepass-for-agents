KeePass for agents

A local credential gateway — agents get logins without ever seeing your secrets.

What you just saw

An agent (a CLI tool, MCP server, or script running on this PC) asked to use one of your KeePass databases — for example to unlock it, add an entry, or sync browser cookies. This page opened so that you, the operator, can approve or deny that request. Nothing happens without your approval here.

The security promise

Your master password travels only from this browser window to the local keepass-agent server on 127.0.0.1, encrypted end to end. It never reaches the agent, never leaves this PC, and is never written to disk or logs.

The agent only ever receives the task result (for example, a filled login form or a stored cookie set) — not the credentials themselves.

How to approve a request

  1. Check the database alias and the requesting agent shown on the approval page.
  2. Enter the master password (and pick a session lifetime).
  3. Press the action button — or Cancel to deny the request.
